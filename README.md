# Supply_chain_shocks

# Project Overview


Calculates the diversions on freight due to a supply chain shock in the US. The model allows for regional shocks (east/west/gulf coast), shocks to specific pipelines and shocks to specific states. Shocks can be to different modes of transport including rail, shipping or pipeline.


# Using the Program

In config.R different shocks can be ran which fills the outputs variable which can be plotted in the plotting.R file
